# Frozen baseline mappings

These JSON files explicitly map native labels to the Kiii² taxonomy; `null` means excluded/out of scope. Unknown labels cause an error. No boundary expansion, gold-dependent category choice or post-hoc tuning is allowed. All 36 gold categories remain in the primary denominator, including categories a baseline cannot produce. Covered-label-only scores must be marked supplementary if added later.

- **Presidio:** version 2.2.364; five Korean recognizers (BRN, driver licence, FRN, passport, RRN) explicitly set to `ko`; email and KR-region phone recognizers; threshold 0.3. Calls pattern recognizers directly, without spaCy/context boosting. Email uses the bundled tldextract 5.3.2 suffix snapshot with network refresh disabled. Frozen custom account rule requires the Korean account prefix; it does not infer securities-account identity. Card rule uses 13–19 digits with optional separators and Luhn validation. This is a configured rule baseline, not every feature of Presidio AnalyzerEngine.
- **ko-pii:** version 1.16.0, `detect_all(normalize=False)`. Raw text mode preserves original offsets; no benchmark-specific detector tuning. Ambiguous labels such as employee IDs, court cases and generic document IDs are excluded. AGE/DT_BIRTH map to dob_age, POSITION to employer_affiliation. Public organizational values can still be false positives; no gold filter removes them.
- **OpenMed:** `OpenMed/privacy-filter-multilingual`, revision `f914f18d909d541d288dfda44a4d0b6bdb638d57`; native Transformers token classification. Argmax BIOES grouping, explicit 1024-token windows/128 overlap by default, all windows covered. This is not the OpenMed wrapper's Viterbi decoder. Exact duplicates are removed; competing/clipped spans survive. FIRST/MIDDLE/LASTNAME map individually to person_name without merging to gold boundaries. Generic SSN is not treated as Korean RRN; ACCOUNTNAME, organization names, amounts, currency and other ambiguous/non-personal labels are excluded. BANKACCOUNT/IBAN map to bank_account_no, never conditionally to securities_account_no. Address fragments and location mentions follow the fixed file mapping.

Native label coverage and boundary conventions differ substantially from the 36 benchmark categories. Record these limitations in the paper; do not portray full-category F1 as a language-only comparison. JSON mappings and source files are hashed into each run. OpenMed GPU/native model execution must still be tested on the assigned host.

Sources: [ko-pii](https://github.com/Marker-Inc-Korea/ko-pii), [Presidio recognizers](https://github.com/microsoft/presidio/tree/main/presidio-analyzer/presidio_analyzer/predefined_recognizers), [OpenMed model card](https://huggingface.co/OpenMed/privacy-filter-multilingual).
