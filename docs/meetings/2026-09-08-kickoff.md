- 참석: 한울(AIM), 성현(토스증권)
- 채널: 카톡 (오전 8:17–8:32)

## 논의

**한울 제안**
- K-Financial PII Benchmark. 합성 데이터. 한국 개인정보보호법 + 금융규정상 외부 반출 불가 택소노미 기준.
- long context, multi-PII 가상 데이터에서 (1) 스팬 추출 (2) 비식별화 두 과업. "누가누가 잘 막나" 리더보드.
- 워크샵 타겟, 2~3주 집필 예상. 가제 "Kiii Kiii — Korean personally Identifiable Information …".

**성현 제안**
- 법적 PII(계좌·이름·주민번호)만 하는 기존 관행을 넘어, 반출돼도 법적 문제는 없지만 AI로 악용하면 위험한 정보를 포함:
  상담 내용, 민원/문의, 투자성향, 서비스 이용시간 등 행동정보.
- 문제의식: "개인정보 + 행동정보를 AI에 먹여 나오는 초개인화 피싱".
- 단, 이건 문제제기로만 넣고 메인 타겟으로 안 해도 좋다.

**실무 제약 (성현)**
- 토스증권은 외부 API 호출에 PII가 붙으면 의심사례로 전부 차단 → 토스 쪽 데이터 증강은 로컬 모델로만 가능.

**한울 반응**
- adversarial attack까지 넣는 것에 긍정적이나, 그러면 데이터가 policy + context + prompt 3층이 되어야 하는지 고민.
- Legal PII와 "금융고객 식별가능성"을 분리하는 방향.
- 결론: 행동정보 축도 택소노미화만 되면 넣을 수 있다.
