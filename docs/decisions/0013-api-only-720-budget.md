# ADR-0013: 720건 API 생성, 총 추정 예산 $150

- 날짜: 2026-09-18
- 상태: accepted
- 대체 범위: ADR-0012의 Qwen 144건 및 예산 미정; 기존 API/로컬 80:20 생성 비율의 이번 720건 적용

## 근거와 결정

사용자가 “$150 상한”, “전부 GLM Deepseek(다시 정상 되면) 으로해”라고 명시했다. Qwen 서버를 기다리지 않고 GLM-5.2-FP8로 720개 계획을 실행한다. DeepSeek는 실제 생성 호출로 정상화가 확인될 때 선택할 수 있으나, 모델 목록 조회만으로 복구를 판단하거나 자동 전환하지 않는다. 2160건 확대는 이번 단계 결과 확인 후 별도 결정한다.

`data/corpus/main-720-v2/0918-05`에 입력과 코드 해시를 고정한다. 이전 파일럿 및 main-720-v1 초안은 보존하고 새 코퍼스에 섞지 않는다. 360개 계획 셀마다 2건이다. 생성 모델은 평가에서 generator로 식별하며, 이번 코퍼스에는 로컬 생성기 비교군이 없다는 제한을 명시한다.

## 생성 및 중단 규칙

- compose_v6는 v5에 접근매체 값/사건 설명 구분과 성별·국적 표 형식 예시를 추가한다. 검증 기준·택소노미·profiles_v1은 유지한다.
- 2개 독립 실행 흐름에 $75씩 할당하여 동시 요청과 보정을 합쳐 최대 $150의 추정 예약 예산을 사용한다. 반환 토큰 사용량으로 정산하고 미수신 요청은 최대 예약액을 유지한다. 제공자 청구 내역 자체를 제한하는 계정 기능은 아니다.
- 완성된 검증 실패 응답만 원문과 오류를 주고 최대 한 번 보정한다. 불확실 요청은 자동 재호출하지 않는다. 각 원문·비용·계보를 보존한다.
- 각 흐름은 10건 처리 이후 누적 보정 후 통과율 70% 미만 또는 연속 불확실 요청 3건이면 중단한다. 예산 부족이나 예약 초과도 중단한다. 중단된 흐름은 자동 재개하지 않는다.
- 720개 계획 처리와 720개 검증 통과는 구분한다. 미해결 문서는 누락으로 보고하고 임의 복제·파일럿 혼합으로 수를 채우지 않는다. 후속 보충도 이 예산의 잔여액 안에서 별도 실행 이력으로 처리한다.

## 품질 한계

프로필 관계·성별 분포 편중, 작은 식별자 사전, 원자적 속성에 대한 2어절 규칙, hard-negative 표제 단서는 기존 제한으로 남는다. 자동 통과는 사람 검수 완료가 아니며, 실제 길이 분포·정보 주체·상담내용 경계의 표본 검수가 2160건 확대의 판단 근거다.
