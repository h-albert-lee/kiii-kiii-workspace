# ADR-0017: 사용자 요청으로 GLM 동시성 4 적용

- 날짜: 2026-09-20
- 상태: accepted
- 근거: 사용자가 “바로 4 가자”라고 지시했다.

현재 실행 중 문서를 완료한 뒤 순차 실행기의 다음 요청을 차단하고 새 `parallel-0920-02` 실행으로 전환한다. 전환용 비어 있는 다음 요청 폴더에는 HANDOFF_PAUSE.txt를 두며, 이 폴더의 manifest 부재 오류는 의도적 로컬 중단으로 기록한다. 제공자 장애로 집계하지 않는다.

기존 성공 문서와 격리 목록을 보존한다. 미완료 계획을 4개 서로 겹치지 않는 묶음에 배정하고, 기존 사용량·불확실 예약을 뺀 $150 잔여 예산을 4등분한다. 각 묶음은 최초 생성·제한적 HTTP 재시도·보정을 순차 처리한다. 동시 요청은 최대 4개다. 예산을 묶음 간 자동 재배분하지 않아 사용량 집계 경쟁으로 인한 과지출을 막는다.

스트리밍·모든 길이 구간 출력 상한 65,536·compose_v7·기존 중단 기준은 유지한다. 주기적 LLM 확인은 하지 않는다. Astra 전환 조건부 승인은 ADR-0016대로 유지하되 자동 OpenAI 제출은 구현되어 있지 않다.
