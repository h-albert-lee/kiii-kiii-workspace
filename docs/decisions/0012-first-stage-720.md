# ADR-0012: 720건을 먼저 생성·평가하고 2,160건 확대 판단

- 날짜: 2026-09-18
- 상태: accepted (1차 목표 건수 확정; 예산·Qwen 접속 정보 대기)
- 근거: 사용자 지시 "일단 720건 해보고 괜찮으면 2160건 가자".
- 관련: ADR-0007, ADR-0010, ADR-0011

## 결정

1. 1차 목표는 720건이다. 기존 API 80%·Qwen 20% 설계에 따라 GLM-5.2-FP8 후보 576건, Qwen 비교군 144건으로 구성한다. Qwen을 GLM으로 자동 대체하지 않는다.
2. 문서유형 10 × T-level 4 × 고객 수 3 × 길이 3 = 360개 셀을 각 2회 포함한다. 기존 계획 생성기의 전체 셀 순회 특성상 T-level 최종 수량은 각 180건이며 가중 비율 25/30/25/20이 아니다. 이 실현 분포를 기록한다.
3. 본 단계 문서 ID는 `kiii-main-v1-00001` 형식으로 파일럿과 구분한다. 720건은 요청 횟수 목표가 아니라 최종 검증 대상 문서 목표다. 불합격·미수신 요청을 완료 건수에 포함하지 않는다.
4. 2,160건은 품질·비용을 확인한 후의 확대 목표이며 자동 제출하지 않는다. 통과율, 범주·유형·변형·길이별 분포, 주체·경계 사람 표본 검수, 생성기 차이를 보고 결정한다.
5. GLM 예산 상한과 Qwen 엔드포인트·모델 ID를 확인한다. 그동안 계획 분리·재현성 기록 등 오프라인 준비를 진행한다. 기존 시험의 불확실한 요청을 임의로 재호출하거나 기존 Astra 파일럿을 720건에 합산하지 않는다.

## 산출물과 한계

- `data/corpus/main-720-v1/plan.jsonl`, `plan.api.jsonl`, `plan.qwen.jsonl`, `stage.json`.
- 현재 compose_v5 기준 최초 API 요청의 보수적 예약액 합산 약 $90.68. 보정·Qwen 비용 제외, 계정 실제 청구액 보장은 아니다.
- 기존 10종 시험은 최종 7건 통과, 1건 미해결, 2건 서버 오류였다. 초기 프로필 분포와 원자적 속성의 2어절 경계 규칙도 검토 사항이다. 이 한계를 숨기고 대량 생성을 완료 처리하지 않는다.
