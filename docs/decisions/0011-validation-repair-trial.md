# ADR-0011: 검증 실패 원문에 대한 1회 보정 시험

- 날짜: 2026-09-18
- 상태: accepted (사전 시험 한정)
- 근거: 사용자가 개선 후 전체 생성을 요청했고, 10종 시험에서 반복 형식 오류를 확인함.
- 관련: ADR-0010

정상 종료했지만 검증에서 거부된 compose_v5 응답만 별도 작업에서 한 번 보정한다. 계획·프로필·사건 사실을 유지하도록 요구하고 원문과 검증 오류를 제공한다. 식별자 값을 코드 밖에서 만들거나 오류 태그를 단순 삭제하여 통과시키지 않도록 지시한다. 보정본도 같은 검증을 받는다.

최초 시험 대상은 `kf-00002`, `kf-00004`, `kf-00001`의 3건이며 추정 예산 상한 $0.65를 적용한다. 원본은 변경하지 않는다. 각 보정 응답에 부모 원문 해시·오류·시도 횟수 1을 기록하며, 보정본에 다시 보정을 적용하지 않는다. 출력 잘림·사용량 불명·API 오류는 이 보정 경로에 자동 투입하지 않는다.

최초 통과율과 보정 후 통과율·전체 비용을 구분해 보고한다. 자동 통과는 사람 검수 완료를 뜻하지 않는다. 본 생성의 보정 정책은 이 시험 결과와 예산을 확인한 뒤 확정한다.
