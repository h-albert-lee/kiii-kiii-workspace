# ADR-0009: 생성 문법을 명시한 compose_v3 소량 재시험

- 날짜: 2026-09-18
- 상태: accepted
- 근거: 사용자가 ADR-0008 시험 후 문법 안내를 보강한 재시험을 승인함.
- 관련: ADR-0002, ADR-0006, ADR-0008

## 결정

1. `compose_v2`를 보존하고 `compose_v3`에 지원 은행 목록, 속성 subtype 콜론 문법, 2어절 속성 경계 예시, 주체 연결 규칙을 명시한다. 지원 은행 목록은 생성 코드의 목록에서 주입한다.
2. 검증기·파서와 기존 gold를 바꾸지 않는다. 단순히 통과율을 올리기 위해 출력 오류를 자동 교정하거나 검증 기준을 완화하지 않는다.
3. 이전 계획 중 짧은 문서 4건(피싱 신고, 보험금 청구, 민원, KYC)을 그대로 선택하여 DeepSeek와 GLM에 적용한다. 기존의 동일 계획 응답과 비교하며, 실패를 관찰한 표본에 대한 재시험이라는 한계를 명시한다.
4. 제공자 공식 문서에서 추론량 제어를 지원하지 않는다고 확인했으므로 서버 기본 추론과 기존 호출 옵션을 유지한다. 프롬프트 변경과 추론 설정 변경을 동시에 시험하지 않는다.
5. DeepSeek 초기 서버 오류 후 가장 짧은 문서 1건을 제한적으로 확인했다. HTTP 503 `model ... is temporarily unavailable`로 확인되어 추가 호출을 중단한다. 이 상태는 생성 품질 실패로 집계하지 않는다.
6. 자동 검증과 별도로 문서의 주체 연결·사건 일관성·경계·내부 ID 노출을 AI가 검토한다. 사람 gold 또는 IAA로 취급하지 않으며 결과를 본 코퍼스에 자동 병합하지 않는다.
