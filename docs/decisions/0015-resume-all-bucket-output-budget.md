# ADR-0015: 모든 길이 구간의 출력 여유 확대 및 생성 재개

- 날짜: 2026-09-20
- 상태: accepted
- 근거: 사용자가 생성 계속 진행을 지시했다. 0918-06에서 4k 문서 00029가 출력 32,000토큰 중 추론 26,442토큰을 사용하고 length로 종료했다.

모든 길이 구간의 최초 생성·보정 출력 상한을 65,536으로 통일한다. 본문 목표 분량과 compose_v7 검증 기준은 유지한다. 요청별 최대 비용 예약도 같은 한도로 계산한다.

기존 실행은 덮어쓰지 않고 `data/corpus/main-720-v2/recovery-0920-01`에서 재개한다. 기존 통과 26건은 건너뛰며 실패·미시도 계획 694건을 처리한다. 이전 실행과 시험의 사용량 환산/불확실 예약 $5.49383366를 이월하고 총 $150에서 제한한다. 이전 연결 오류 00019도 이번 명시적 재개 요청에 따라 새 시도로 처리하며 과거 예약액은 유지한다. 격리된 시험본은 계속 제외한다.

동시 1건, 스트리밍, 일시적 HTTP 오류 1회 지연 재시도, 완성본 주석 보정 1회, 반복 서버 오류·출력 잘림·낮은 검증 통과율 중단 규칙은 유지한다. 2160건으로 자동 확대하지 않는다.
