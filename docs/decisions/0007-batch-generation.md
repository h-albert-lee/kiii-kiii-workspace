# ADR-0007: API 주생성에 Batch 경로 추가, Qwen 비교군 유지

- 날짜: 2026-09-16
- 상태: accepted
- 근거: 사용자가 Batch 생성 기능 추가를 요청했고, Qwen 비교군의 목적을 확인한 뒤 서버를 준비하기로 함.
- 관련: ADR-0002, ADR-0006

## 결정

1. Astra `api-main`에 OpenAI Batch 경로를 추가한다. 계획·프롬프트·호출 옵션과 식별자 후처리는 동기 생성과 같다. 이는 전송 방식 변경이며 생성 모델 변경이 아니다.
2. 준비·제출·조회·수집·재시도 준비·병합을 분리한다. 유료 작업은 명시적 제출에서만 시작한다. 성공한 요청은 재시도하지 않고, 제출 결과가 불명확하면 자동 재제출을 차단한다.
3. 제출할 프롬프트·계획을 저장하고 해시로 고정한다. 결과는 행 순서가 아닌 문서 ID로 연결한다. 실패·잘림 응답과 사용량도 보존한다.
4. Qwen 20% 비교군은 유지한다. 파이프라인 실행의 필수 의존성은 아니며, 다른 생성기의 문서에서도 모델 평가 경향이 유지되는지 확인하는 연구 설계다. 사용자 측에서 서버를 준비한다.
5. 생성기 간 순위 상관만으로 생성 모델 편향을 제거했다고 주장하지 않는다. 같은 문서 조건을 비교하고, 표본 크기·분포 차이와 불확실성을 함께 확인해야 한다.

## 영향

- `src/generate/batch.py`: Batch 수명주기 및 실패 요청 재시도/병합.
- `src/generate/compose.py`: 동기/Batch가 같은 호출 옵션 사용.
- 운영 방법: `docs/guide/batch-generation.md`.
- 이번 변경은 코드·오프라인 테스트까지이며 실제 Batch 제출이나 추가 문서 생성은 수행하지 않았다.
- 본 데이터의 구체적인 건수·생성 프롬프트 품질 보완은 이 결정에서 확정하지 않는다.
