# ADR-0010: 공통 고객 프로필·의미 검증과 예산 제한 생성

- 날짜: 2026-09-18
- 상태: accepted (구현·사전 검증 범위; 본 코퍼스 건수·예산은 별도 확정 필요)
- 근거: 사용자가 내용 일관성을 더 개선하고 전체 생성을 진행하도록 요청함.
- 관련: ADR-0002, ADR-0006, ADR-0009

## 결정

1. `profiles_v1`은 계획 seed로 생년월일·성별·국적·가족관계·주소 그룹을 결정한다. LLM에는 속성 사실과 관계만 제공하고 식별자 값은 전달하지 않는다. 주민번호와 외국인등록번호는 같은 프로필을 사용해 코드로 생성한다. 같은 주소 그룹은 동일 주소 값을 사용하되 주체별 스팬·entity 귀속은 유지한다.
2. 문서 기준일은 재현성을 위해 2026-09-01로 고정한다. 나이는 이 기준일의 만 나이이며 과거 사건 시점의 나이를 별도로 생성하지 않는다. 프로필은 합성이며 실제 고객 자료를 사용하지 않는다.
3. `compose_v4`에 프로필과 주체 귀속 규칙을 추가한다. `compose_v5`는 주체별 허용 신분 식별자와 YAML의 속성 정의·주의사항을 추가한다. 이전 프롬프트·응답은 그대로 보존한다.
4. v4/v5에서만 프로필 불일치, 미등록 주체, 직원에게 귀속된 고객 상담 메모, 내부 주체 ID 노출, 알 수 없는 속성 subtype 등을 거부한다. 이는 제한된 자동 검증이며 모든 의미 오류를 탐지한다는 주장은 하지 않는다. 기존 v1~v3에 새 규칙을 소급 적용하지 않는다.
5. 한국 여권 생성기는 외국 국적자에게 사용하지 않는다. 외국 국적자에게 한국식 식별자를 억지로 넣는 응답은 고쳐서 채택하지 않고 거부한다.
6. 전체 생성 전 10종 문서·1k/4k/16k 길이의 기존 계획 전체를 재시험한다. 대량 생성 건수·예산, GLM으로 교체할 범위는 별도 확정한다. Qwen 20% 비교군은 자동 삭제하지 않는다.
7. MangoInference 본 생성은 입력과 소스 해시를 고정하고 요청 전 비용을 보수적으로 예약하는 실행기를 사용한다. API 오류·사용량 불명·검증 실패 시 중단하며, 불명확한 요청이나 완료 문서를 자동 재호출하지 않는다. 예산은 고정 단가에 의한 추정 한도로 실제 계정 청구액을 보장하지 않는다.

## 제한 및 후속 작업

- 프로필 v1은 성인 위주, 대한민국·미국 국적, 고객 1·2(단일 고객은 tp1) 배우자 관계의 제한된 초기 설계다. 본 코퍼스 설계에서 인구통계·가족관계 편중을 검토해야 한다.
- 일반적인 문서 사실·금액·날짜 간 정합성, 모든 카테고리 의미 경계, 슬롯 밖 누락 PII 등은 자동 검증만으로 완결되지 않는다. 사람 표본 검수가 필요하다.
- 기존 생성 사전의 다양성, hard negative 표제 단서 및 STT pre-mask 미구현 문제는 별도 남아 있다.
- 구현: `src/generate/profiles.py`, `src/generate/campaign.py`; 운영: `docs/guide/mango-campaign.md`.
