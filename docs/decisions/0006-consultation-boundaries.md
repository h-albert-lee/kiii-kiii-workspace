# ADR-0006: 상담내용 태그 경계의 운영 기준과 파일럿 보정

- 날짜: 2026-09-16
- 상태: accepted (운영 기준); 보정 주석은 provisional
- 근거: 사용자가 상담내용 경계 판단을 위임함. ADR-0004 결정 12의 포함·제외 규칙을 구체화한다.
- 범위: 기존 택소노미 v1.2의 해석과 주석 경계. 카테고리·subtype·법적 분류는 변경하지 않는다.

## 문제

파일럿 생성 프롬프트의 속성 목록은 상담내용의 상세 운영 규칙을 전달하지 않는다. 생성된 태그에는 고객별 사유와 일반 보안·절차 안내가 함께 포함된 사례가 있다. 구조 검증만으로 이 의미 오류를 판정할 수 없다.

## 결정

1. 고객의 구체적인 요청·사유·피해 경위, 고객 상황을 기록한 상담사 메모를 포함한다. 고객을 호명했다는 이유만으로 절차 안내를 포함하지 않는다.
2. 일반 상품 설명·보안 안내·업무 전달·추후 확인/회신 약속은 제외한다. 실제 접수·보류·미실행 상태, 고객별 증빙 결손 또는 사건에 특화된 심사 판단은 포함할 수 있다. 가정적 상황은 실제 고객 사정으로 취급하지 않는다.
3. 같은 발화 안에서 포함되는 사실과 일반 안내를 분리한다. 서로 다른 사실 절은 분리하고, 이유와 요청이 연결된 절은 의미가 유지되는 최소 구간으로 남긴다. 정확한 원문 구간만 사용하며 문법을 고쳐 쓰지 않는다.
4. 식별자 확인만 남는 구간에서 상담내용 태그를 제거하더라도 내부의 이름·계좌·연락처 등 다른 태그는 보존한다. 다른 카테고리와의 중복 정책, 누락 주석, 주체 연결은 이번 경계 보정에서 변경하지 않는다.
5. API 80건 중 문서 유형별 가장 짧은 문서 1건씩 총 10건을 기준 사례로 검토한다. 전체 80건의 상담내용 태그 3,408개 중 기존 태그 64개만 이번 검토 대상이다. 이 표본으로 코퍼스 전체 오류율을 추정하지 않는다.
6. 원본과 생성 프롬프트를 보존하고, 출처 해시·개별 결정·수정 이유가 있는 별도 보정본을 만든다. 보정본은 Codex 단독 검토에 따른 임시 주석이며 사람 gold 또는 IAA 결과로 보고하지 않는다.
7. 기존 사람 검수용 30건 중 기준 사례와 겹치는 6건을 같은 문서 유형의 다른 문서로 교체한 v2를 준비한다. 원래 30건도 보존한다. 사람 검수 전 공통 절 단위를 확정해야 하며, κ 계산과 subtype 축소 판단은 아직 수행하지 않는다.

## 결과와 후속 영향

- 기존 64개 태그 중 33개 유지, 18개 경계 조정·분할, 13개 제외. 분할 후 상담내용 태그는 56개이다. 본문·다른 카테고리·식별자 태그는 모두 보존했으며 10건 모두 기존 구조 검증을 통과했다.
- 기준: `docs/guide/consultation-annotation.md`
- 결정 내역: `docs/reviews/consultation-calibration-v1.json`
- 재현: `.venv/bin/python scripts/apply_consultation_review.py`
- 산출물: `data/corpus/pilot-0.1/review/consultation-calibration-v1/`
- 아직 검토하지 않은 기존 상담내용 태그는 3,344개이다. 누락 여부와 다른 카테고리의 의미 정확성은 별도 검토가 필요하다.
- 새 생성 프롬프트에 이 규칙을 반영할 때는 새 버전을 사용한다. 현재 API80과 비교할 로컬20은 계획대로 `compose_v2`를 사용하고, 후속 주석 검토 기준을 동일하게 적용한다. 이번 작업에서는 유료 생성 호출을 하지 않았다.
