# ADR-0038 — Freeze completed runs for the manuscript

Date: 2026-10-01. Status: accepted by the operator's request to stop collecting experiments and write using completed evaluations. Supersedes the planned roster/completion requirements of ADR-0034/0035, not their historical records or scoring rules.

## Scope

Use all completed, independently replay-verifiable conditions available at `feat/exp-eb@9e0570a` and `feat/exp-gemma@46cac91`, plus the two CPU baselines. This admits Qwen3-30B-A3B, EXAONE 4.5 33B and five Gemma 4 variants as post-hoc extensions. Retain complete Qwen 2B full and Qwen 4B local; exclude their pilot-only opposite conditions without imputing scores. Planned but unevaluated API models are omitted. Exclusion is by completed-artifact availability, not performance. No new inference or spending is authorized. The target inventory is 12 LLMs / 22 completed LLM conditions plus 3 baselines, subject to replay verification.

Report original cohorts and execution blocks separately: 1,440 documents except Kanana 1.5 8B's 1,438. Do not alter gate hashes, bypass headline exporter checks, pool unequal cohorts or claim one independently verified all-model capacity gate. Within-model full/local comparisons require identical data, partition, configuration and gate. Native measurement files remain unavailable; explicitly disclose this reproducibility limitation rather than calling their maxima independently verified. Model/operator sampling, server and precision differences are recorded; Gemma 31B uses FP8 weights and KV cache, other Gemma runs BF16. Thus cross-family differences cannot establish a causal model-size effect.

## External runner replay

Gemma artifacts were generated by an external `gemma_runner`, not `src.eval.execute`. Preserve that source provenance and its hashes verbatim. Repository scoring can still be independently applied to archived raw responses if complete coverage, byte-identical gold and reconstructed request hashes agree. Use a distinct offline external-runner diagnostic module. It must reconstruct all requests, verify every request/model/raw/data/taxonomy hash, replay every strict metric, breakdown, document and failure, and retain both the original runner hashes and actual replay scorer hashes. Foreign runner source equivalence and server execution are not established by output replay. Never fabricate a repository source stamp, edit the original result or make it eligible for the existing headline exporter.

The external module uses unchanged ADR-0036 itemwise/fence and invalid-item penalties. ADR-0037 decomposition may consume such a replay artifact only after verifying its explicit external provenance and repeating strict/itemwise per-document and request-plan checks. This does not relax live execution or cohort gates. Original native-run diagnostics retain their existing source guard.

## Manuscript

Present end-to-end strict F1 as primary and post-hoc format/grounding/detection diagnostics separately. Preserve all gold and failed requests. Disclose absent representative pilot calibration, operator-reported native limits, external runner, sampling differences and quantization. Use completed paired conditions for descriptive paired statistics, not missing pairs. Write results, discussion and conclusion with actual measured values; remove pending experiment templates. Maintain four main-text pages, anonymity and native Overleaf comments.
