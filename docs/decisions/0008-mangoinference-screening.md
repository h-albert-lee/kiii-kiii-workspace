# ADR-0008: MangoInference 생성기 시험, 주생성기 전환 보류

- 날짜: 2026-09-18
- 상태: accepted
- 근거: 사용자가 MangoInference 크레딧과 키를 제공하고 실제 호출을 요청함.
- 관련: ADR-0002, ADR-0007

## 결정

1. 기존 Astra 사전 시험의 계획 10건과 `compose_v2`를 사용해 DeepSeek-V4-Pro-0813, GLM-5.2-FP8을 시험한다. API 키는 제공자별로 분리하고 원문·실패·사용량을 보존한다.
2. 출력 한도에 도달하면 새 요청을 중단하고 이미 실행 중인 응답만 수집한다. 한도를 늘리거나 자동 재시도하지 않는다.
3. 실제 저장된 응답은 DeepSeek 5건, GLM 7건이며 자동 검증 통과는 각각 0건, 1건이다. 이는 현재 프롬프트·제공자 설정의 적합성 시험이며 모델의 일반적인 성능 순위가 아니다.
4. 주생성기 Astra 및 Qwen 20% 비교군 계획을 유지한다. 이번 시험 응답은 기존 파일럿과 분리하며 본 코퍼스에 병합하지 않는다.
5. 재시험에 앞서 지원 은행 목록·subtype 태그 예시를 명확히 하고, 추론 제어 지원 여부를 확인한다. 새 프롬프트는 별도 버전으로 보존한다. 재시험이나 대량 생성은 이번 실행에 포함하지 않는다.

## 근거 및 영향

- 은행 옵션과 속성 태그 형식 오류가 많았고, 두 모델 모두 장문에서 출력 한도에 도달했다. 프롬프트 설명 부족도 있어 이를 모델 능력만의 문제로 해석하지 않는다.
- 저장된 신규 응답의 비용 추정 합계는 $0.828964이며 실제 크레딧 차감액은 확인하지 않았다.
