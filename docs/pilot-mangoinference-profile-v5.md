# 프로필·정의 보강 후 전체 10종 시험 — 2026-09-18

본 코퍼스 대량 생성 전 시험이다. **기존 10개 계획 전체를 요청했으나, 최종 자동 검증 통과본은 7건이다.** 피싱 신고 1건은 미해결이고 카드 명세서·장문 증권 보고서 2건은 서버 오류로 응답을 받지 못했다. 본 생성은 아직 시작하지 않았다.

## 개선 내용

- 코드가 만드는 고객 프로필을 프롬프트와 식별자 후처리에 함께 적용한다. 주민번호·외국인등록번호의 생년월일·성별, 가족의 동일 주소를 맞춘다. LLM은 식별자 값을 받거나 직접 쓰지 않는다.
- 날짜·나이·성별·국적 불일치, 미등록 주체, 직원에게 귀속한 고객 상담 메모, 본문 내부 ID 노출, 잘못된 속성 subtype 등을 추가 검증한다.
- v5는 택소노미의 속성 정의·주의사항과 주체별 허용 신분 식별자 목록을 명시한다. 기존 v1~v3 처리 동작과 원문은 보존했다.
- 본 생성용 실행기는 입력·소스 해시 고정, 요청 전 비용 예약, 완료 건 중복 호출 방지, 오류·검증 실패 시 중단, 별도 1회 보정과 원문 계보 기록을 지원한다. 오프라인 테스트 58개 통과.

프로필 v1은 고정 기준일 2026-09-01, 성인·대한민국/미국 국적·배우자 관계 위주의 초기 설계다. 일반적인 자유서술 사실, 모든 경계와 누락 스팬, 인구통계 분포까지 보증하지 않는다. 본 코퍼스에 쓰기 전 프로필 분포와 사람 표본 검수가 필요하다.

이번 개선 작업에서 사용량을 받은 응답의 비용 추정 합계는 **약 $0.94**이다. 최초 v3 재시험 등 이전 턴 비용은 제외했다. 서버·연결 오류 요청은 사용량을 받지 못했으므로 실제 차감액이 더 클 수 있다. 보정 실행기에는 연결 오류 요청의 예약액 $0.172560을 별도로 남겼으며, 이를 실제 청구액으로 취급하지 않는다.

v4 거부 1건은 미국 국적 고객에게 한국 여권 생성기 슬롯을 쓴 사례다. v5에 주체별 허용 목록을 추가했다.

## 보정 및 해석

보정은 정상 종료했지만 거부된 v5 문서만 대상으로 원문·검증 오류·같은 프로필을 제공하고 한 번 재작성한 것이다. 원문은 수정하지 않았고 부모 응답 해시·오류·attempt=1을 기록했다. 오류·불확실한 요청은 보정 성공으로 집계하지 않는다.

- 대출 약정서는 성별·국적 한 단어 태그 6곳을 2어절 이상으로 확장했다. 전체 diff를 확인했으며 다른 문장과 숫자열은 동일했다. 이는 현재 형식 규칙에 맞춘 보정이지 모델의 의미 품질이 크게 개선됐다는 증거는 아니다.
- 상담 전사는 접근매체 사건 설명을 고객 상담 메모로 바꾸고 코드가 채우는 접근매체 슬롯을 추가했다. 투자성향 오타와 성별 표현도 바뀌었다. 태그만 바꾼 동일 본문이라고 주장하지 않는다.
- 최소 2어절 규칙이 성별·국적 같은 원자적 속성에 불필요한 문구를 유도할 수 있다. 현재 시험에서는 기준을 바꾸지 않았으며, 본 코퍼스 전에 경계 정책을 재검토해야 한다.

자동 검증 통과는 사람 gold·IAA 또는 모든 의미 오류가 해결됐다는 뜻이 아니다. 특히 장문 16k는 이번 서비스 오류로 검증하지 못했다. 이 상태에서 수백~수천 건을 바로 생성하면 같은 오류와 비용이 누적될 수 있어 대량 제출은 보류했다.

## 본 생성 준비 상태

사용자에게 전체 범위(10종 시험만 / 720건 단계 / 2,160건 목표)와 크레딧·예산 한도를 질문했으며 아직 답변을 받지 못했다. `data/corpus/main-candidate-720/`에 **제출하지 않은 720건 초안**만 만들었다. 360개 셀을 각 2회 포함하고 API 576·Qwen 144건으로 나뉜다.

API 576건의 입력 UTF-8 바이트 기반 보수적 예약액과 출력 최대 32,000토큰을 합산하면, 현 콘솔 단가에서 **약 $90.68**다. 이는 최초 1회 요청에 대한 추정 예약액이며 실제 청구액 보장·평균 비용 예측이 아니다. 보정·Qwen 비용은 제외된다. Qwen 엔드포인트도 아직 제공되지 않았다.

남은 것은 범위·예산 확정, 미수신 장문·미해결 피싱 문서의 처리, 프로필 분포와 경계 정책 검토다. 기존 Astra 80건과 이번 GLM 시험을 본 코퍼스에 임의로 합치지 않았다.
