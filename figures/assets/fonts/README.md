# Korean figure font

Nanum Gothic Regular is bundled under the SIL Open Font License 1.1; see `OFL-NanumGothic.txt`.

Source: https://github.com/google/fonts/tree/main/ofl/nanumgothic (retrieved 2026-09-16).

The TrueType font is subset-embedded in the PDF. `KIII_KOREAN_FONT` may override it when rebuilding. The Overleaf compiler does not need this font installed to include the generated PDF.
